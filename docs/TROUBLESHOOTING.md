# 排查与常见问题

如果安装后未生效，建议先在 LSPosed / Xposed 框架日志中搜索 `CircleIcons` 查看运行状态：

- `active`：已成功找到接口并挂载 Hook。
- `unavailable on this ROM`：当前系统缺少相应接口（例如较老的 Android 版本没有新的通知缓存机制，属正常现象）。
- `installation failed`：接口或框架不匹配，可查看日志后附带的具体错误原因。

---

## 1. 桌面图标没有变成圆形？

1. **检查蒙版设置**：确认系统或当前桌面支持并启用了“圆形”自适应图标蒙版。
2. **重启桌面或手机**：安装或更新后需重启桌面进程使缓存生效（无需清除桌面数据，清除会导致桌面排布丢失）。
3. **已适配的应用不作变动**：如果应用本身已经提供了自适应图标规范，模块会直接放行，由系统原生渲染。

## 2. 状态栏通知依然是白色方块？

1. **确认作用域**：确保在框架管理器中勾选了**系统界面 (SystemUI)** 并已重启生效。
2. **特殊图标限制**：如果第三方应用提供的通知素材本身就是一张完全没有透明度、对比度极低的单色方块图，可能无法提取出清晰的轮廓图案。
3. **颜色显示**：状态栏着色完全遵循系统原生的深浅色模式与壁纸动态取色逻辑。

## 3. 如何彻底停用或卸载？

直接在框架管理器中关闭本模块并重启手机即可恢复原生状态。模块不会篡改系统分区或破坏应用数据。

## 4. 反馈 Issue

遇到兼容性问题欢迎在 GitHub 提交 Issue，请附带：
- 设备机型与系统 / ROM 版本（如 Pixel 7, LineageOS 21 等）
- Android 版本及 LSPosed 框架版本
- 桌面包名（如果是桌面图标未生效）
- 框架日志中包含 `CircleIcons` 的相关内容（请注意隐去个人隐私信息）
